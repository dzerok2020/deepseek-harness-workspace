# ECC → DeepSeek Harness: ghi chú tích hợp (15/10/2026)

## Cập nhật kiểm chứng bridge (30/10/2026)

Đây là kết quả **so sánh trước cài**, không phải biên bản cài đặt hoàn tất. Phần nghiên cứu ngày 15/10 bên dưới được giữ nguyên theo thời điểm khảo sát; phiên kiểm tra mới dùng DSH `0.2.1-rc.2` và checkout ECC `b92f181b3b748d1abbc2afd94af6aa7d8c8fca29`.

- **Dependency thực tế:** `require.resolve` từ runtime hiện tại báo `MODULE_NOT_FOUND` cho cả `@deepseek-ai/dsh-hooks-claude-code` và `@deepseek-ai/dsh-hook-protocol`. Tám peer còn lại của bridge khớp phiên bản: bảy gói DSH `0.2.1-rc.2` và Cordis `4.0.5`. Vì vậy không áp dụng nguyên văn giả định bridge đã đi kèm runtime trong hướng dẫn ECC.
- **Package đúng phiên bản có tồn tại:** đã tải hai tarball `0.2.1-rc.2` từ npm registry chính thức vào thư mục tạm, đối chiếu SHA-512 với metadata và kiểm tra archive chỉ có đường dẫn tương đối, file/thư mục thường, trong giới hạn kích thước. Cả hai dùng MIT; không chạy install script, không import/chạy hooks và không thay đổi profile. Kiểm tra integrity này không thay thế kiểm toán bảo mật toàn bộ dependency.
- **Không thể đạt đầy đủ hành vi chỉ bằng cài bridge:** source bridge chỉ nhận 7 loại event; config ECC đang khảo sát có 8 loại được dùng, nên generator giữ 23/27 command entries qua 5 loại event và bỏ `PreCompact`, `PostToolUseFailure`, `SessionEnd`. Generator và parser bridge đều không giữ `async`; bridge chạy các command khớp theo thứ tự và chờ từng command.
- **Khoảng thiếu payload/response:** bridge không áp dụng `updatedInput`; `transcript_path` luôn rỗng, `stop_hook_active` luôn `false`. Hook ECC cần transcript, sửa đầu vào tool hoặc nhận diện vòng Stop vì thế không được xem là đã tương đương. Ví dụ cost tracker ECC lấy dữ liệu từ transcript hoặc biến môi trường dự phòng; không có transcript hợp lệ thì không có bằng chứng đo usage/cost đúng.
- **Phân biệt bằng chứng:** đã kiểm metadata, source package và khả năng resolve dependency; chưa mount bridge, chưa kiểm event lifecycle/sandbox trên DSH chạy thật, chưa kiểm chứng tích hợp agents/commands/rules. README bridge có mô tả `SessionStart` vừa awaited vừa detached; source có `await run`, nhưng thứ tự so với request đầu tiên vẫn cần test host lifecycle, không lấy riêng README làm kết luận.
- **Trạng thái quyết định:** người dùng yêu cầu so sánh ECC với DSH trước và muốn đầy đủ hơn skills. Phương án hoàn thiện adapter trong profile thử nghiệm đã được đề xuất nhưng chưa được xác nhận tại thời điểm ghi. Không bật hooks, MCP, memory/learning, model ngoài hoặc ghi đè cấu hình đang dùng trong lượt kiểm chứng này.

Nguồn tái kiểm tra: [metadata bridge đúng phiên bản](https://registry.npmjs.org/@deepseek-ai/dsh-hooks-claude-code/0.2.1-rc.2), [metadata protocol đúng phiên bản](https://registry.npmjs.org/@deepseek-ai/dsh-hook-protocol/0.2.1-rc.2), [generator ECC đã ghim](https://github.com/affaan-m/ECC/blob/b92f181b3b748d1abbc2afd94af6aa7d8c8fca29/scripts/dsh/generate-hooks-config.js), [cost tracker ECC đã ghim](https://github.com/affaan-m/ECC/blob/b92f181b3b748d1abbc2afd94af6aa7d8c8fca29/scripts/hooks/cost-tracker.js).

## Cách cài đúng theo từng agent

- **Claude Code:** hướng dẫn chính là `npx ecc-universal@2.2.3 setup` (Node ≥18; Git và Claude Code ≥2.1 cho plugin); tương đương `pnpm dlx ecc-universal@2.2.3 setup`, `yarn dlx …` hoặc `bunx …`. Có thể dùng lệnh bản địa `/plugin marketplace add https://github.com/affaan-m/ECC` rồi `/plugin install ecc@ecc`. Chọn **một** phương thức cho cùng harness; plugin + full manual install có thể trùng skills/hooks. [README: install](https://github.com/affaan-m/ECC/blob/b92f181b3b748d1abbc2afd94af6aa7d8c8fca29/README.md#install-ecc)
- **Cài chọn lọc/CLI:** `npx ecc-universal@2.2.3 install --profile minimal --target claude` (hoặc checkout nguồn: `./install.sh --profile minimal --target claude`); các profile `core` và `minimal` có thể xem trước với `--dry-run`. Guided hỗ trợ Claude, Codex, Kimi; adapter khác gồm OpenCode, Cursor, Gemini, Qwen… nhưng không nên suy diễn rằng chúng cũng cài được vào DSH. Tên npm là `ecc-universal`, **không phải** `ecc-install` (đó là tên binary). [README: profiles, targets, cautions](https://github.com/affaan-m/ECC/blob/b92f181b3b748d1abbc2afd94af6aa7d8c8fca29/README.md#install-ecc)
- **DSH:** không có `--target dsh`/installer riêng. Clone ECC để giữ nguồn ổn định; với mỗi skill cần dùng, liên kết `skills/<tên>` vào `~/.dsh/skills/<tên>` hoặc dùng thư mục project `.dsh/skills/`; **không chạy** universal installer như thể nó tích hợp DSH. DSH nhận `SKILL.md` trực tiếp; root project `.dsh/skills`, `.agents/skills` được ưu tiên trước root user. Checkout ECC tự có một phần `.agents/skills/` dùng cho Codex. [DSH guide: prerequisites/skills](https://github.com/affaan-m/ECC/blob/b92f181b3b748d1abbc2afd94af6aa7d8c8fca29/docs/DEEPSEEK-HARNESS-GUIDE.md#skills-automatic)

## Bố cục và bề mặt tương thích

- Repo chứa `skills/<name>/SKILL.md` (workflow), `.agents/skills/` (tập con cho Codex), `rules/common/*.md` và `rules/<language>/*.md` (quy tắc), `agents/`, `commands/`, `hooks/hooks.json`, `scripts/dsh/generate-hooks-config.js`, `docs/DEEPSEEK-HARNESS-GUIDE.md`. Skills là bề mặt DSH hỗ trợ tự nhiên; slash commands Claude **không** tự thành commands DSH, native agent dispatch **chưa xác minh**. [Tree cố định](https://github.com/affaan-m/ECC/tree/b92f181b3b748d1abbc2afd94af6aa7d8c8fca29) · [DSH scope](https://github.com/affaan-m/ECC/blob/b92f181b3b748d1abbc2afd94af6aa7d8c8fca29/docs/DEEPSEEK-HARNESS-GUIDE.md#scope)
- Hooks DSH là phương án **tùy chọn, có ảnh hưởng runtime**: sinh JSON bằng `node scripts/dsh/generate-hooks-config.js --ecc-root /path/to/ECC --out ~/.dsh/ecc/hooks-dsh.json`, rồi thêm bare `- insert:` với plugin `@deepseek-ai/dsh-hooks-claude-code` và `configPath` tuyệt đối vào `~/.dsh/profiles/<profile>/cordis.patch.yml`. Cầu nối chỉ nhận command hooks; 23 hooks qua 5/7 events, 3 events chưa hỗ trợ; cấu hình cần tái sinh sau cập nhật ECC. `--dump-config` có thể exit 0 dù patch bị bỏ qua: kiểm tra cả stderr và id plugin trong dump. [DSH guide: hooks/mount/verify](https://github.com/affaan-m/ECC/blob/b92f181b3b748d1abbc2afd94af6aa7d8c8fca29/docs/DEEPSEEK-HARNESS-GUIDE.md#hooks)

## Rủi ro và đề xuất tối thiểu

- **Không chạy installer vào profile hiện tại:** installer có thể viết skills/rules/config vào target của harness và các phương thức cài chồng nhau gây trùng lặp; xem `--dry-run` và đích đến, kiểm tra `git status`/backup trước thao tác. Không tự copy cả `rules/common` vào project đã có `AGENTS.md`: quy tắc `git-workflow.md`, `development-workflow.md`, `testing.md`, `hooks.md` có thể xung đột với hợp đồng Git/test/hook hiện tại. [README: do not stack](https://github.com/affaan-m/ECC/blob/b92f181b3b748d1abbc2afd94af6aa7d8c8fca29/README.md#install-ecc) · [rules guide](https://github.com/affaan-m/ECC/blob/b92f181b3b748d1abbc2afd94af6aa7d8c8fca29/rules/README.md)
- **Không bật hooks hàng loạt:** hook GateGuard có thể chặn lượt edit/write/bash đầu tiên để buộc nêu facts; hooks chạy mã từ checkout được liên kết, tác động lên từng phiên và cần rà soát source/trust trước khi cấp quyền. Nếu thử nghiệm, dùng profile cô lập rồi verify compose và hành vi, không chèn vào web profile đang sử dụng. [DSH guide: verify/scope](https://github.com/affaan-m/ECC/blob/b92f181b3b748d1abbc2afd94af6aa7d8c8fca29/docs/DEEPSEEK-HARNESS-GUIDE.md#verify)
- **Chọn lọc trước:** đọc `skills/verification-loop/` (kiểm chứng), `skills/tdd-workflow/` (test-first) hoặc `skills/security-review/` khi thực sự thiếu năng lực tương ứng; kiểm tra trùng tên với skills DSH đang cài trước khi liên kết. Với rules chỉ cân nhắc từng file `rules/common/security.md`, `rules/common/testing.md`, cộng `rules/<ngôn-ngữ>/` đúng stack; hòa giải nội dung với `AGENTS.md` trước khi dùng, không copy nguyên pack. Đây là **khuyến nghị đánh giá**, không phải xác nhận cần cài vì workspace đã có skills và kỷ luật test riêng.
