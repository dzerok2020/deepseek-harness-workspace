## 2. Công dụng, runtime và giao diện tích hợp

### Graphify — bản đồ quan hệ của codebase

- Tạo **knowledge graph** (đồ thị biểu diễn thành phần và quan hệ), không phải vector store. Code được phân tích AST bằng tree-sitter tại máy; tài liệu/PDF/media có semantic pass tùy chọn qua model. Kết quả gồm `graphify-out/graph.json`, `GRAPH_REPORT.md`, `graph.html`; có `schema_version` và `graphify_version`. Cạnh `EXTRACTED` khác `INFERRED`, nên kết quả suy luận không phải bằng chứng thực thi. [README](https://github.com/Graphify-Labs/graphify/blob/c588b72d936927790a87ad009955078ed40562a3/README.md).
- Python **>=3.10**, macOS/Linux/Windows; một số extra có điều kiện riêng, ví dụ transcription `faster-whisper` cần Python >=3.11. Cài theo tài liệu: `uv tool install graphifyy` hoặc `pipx install graphifyy`, rồi `graphify install`. **Tên PyPI là `graphifyy` (hai chữ y)**, không dùng package cùng tên gần giống. [Manifest](https://github.com/Graphify-Labs/graphify/blob/c588b72d936927790a87ad009955078ed40562a3/pyproject.toml), [README](https://github.com/Graphify-Labs/graphify/blob/c588b72d936927790a87ad009955078ed40562a3/README.md).
- Hai đường độc lập: CLI/skill (`graphify query`, `path`, `explain`; generic Agent Skills qua `--platform agents`) hoặc MCP (giao thức để agent gọi tools), extra `graphifyy[mcp]`, entry point `graphify-mcp`. Server có stdio mặc định và Streamable HTTP; tools gồm `query_graph`, `get_node`, `get_neighbors`, `shortest_path`, `graph_stats`. `graphify install` **không tự thiết lập kết nối MCP**. [README](https://github.com/Graphify-Labs/graphify/blob/c588b72d936927790a87ad009955078ed40562a3/README.md), [server](https://github.com/Graphify-Labs/graphify/blob/c588b72d936927790a87ad009955078ed40562a3/graphify/serve.py).
- **Cho DSH:** ưu tiên thử CLI đọc graph cục bộ hoặc MCP stdio có phạm vi repo rõ ràng; không giả định slash command/hook của Claude Code chạy nguyên trạng trong DSH. Installer có thể sửa instruction files và hooks, vì vậy không chạy tự động trên workspace hiện có. Graph là chỉ mục hỗ trợ tìm đường; vẫn đọc source và chạy test để xác nhận.

### Ponytail — prompt/rules cho coding agent, không phải browser automation

- Cốt lõi là [`skills/ponytail/SKILL.md`](https://github.com/DietrichGebert/ponytail/blob/09c434ab73ca43761c5d8b0c5d341926c2fba710/skills/ponytail/SKILL.md) và bản compact [`AGENTS.md`](https://github.com/DietrichGebert/ponytail/blob/09c434ab73ca43761c5d8b0c5d341926c2fba710/AGENTS.md): đọc luồng thực tế, ưu tiên tái sử dụng code/standard library/platform trước khi viết mới; không cắt validation, security, accessibility. Có review diff, audit repo, debt và các mức `lite/full/ultra/off`. Đây là hướng dẫn hành vi cho model, **không phải enforcement bảo mật hay máy chạy test độc lập**. [README](https://github.com/DietrichGebert/ponytail/blob/09c434ab73ca43761c5d8b0c5d341926c2fba710/README.md).
- Bản rules/skill cần host đọc Markdown; adapters thực thi phụ thuộc host. Claude/Codex/Cursor lifecycle hooks cần **Node.js trên PATH**; package không khai báo `engines` để suy ra Node tối thiểu. Có adapters OpenCode, Pi, Gemini và nhiều agent khác, nhưng tài liệu đọc được **không có adapter DSH riêng**. [INSTALL](https://github.com/DietrichGebert/ponytail/blob/09c434ab73ca43761c5d8b0c5d341926c2fba710/INSTALL.md), [manifest](https://github.com/DietrichGebert/ponytail/blob/09c434ab73ca43761c5d8b0c5d341926c2fba710/package.json).
- Cài chính thức tùy host: Claude marketplace/plugin, Codex plugin, OpenCode npm plugin; host khác dùng skill hoặc rules. Không sao chép đè nguyên `AGENTS.md` hiện có. Band hiển thị chi phí/tests yêu cầu Claude Code **>=2.1.290**, không áp dụng tự động cho DSH. [README](https://github.com/DietrichGebert/ponytail/blob/09c434ab73ca43761c5d8b0c5d341926c2fba710/README.md), [INSTALL](https://github.com/DietrichGebert/ponytail/blob/09c434ab73ca43761c5d8b0c5d341926c2fba710/INSTALL.md).
- **Cho DSH:** chỉ cân nhắc chọn lọc nguyên tắc thành skill thủ công sau khi kiểm tra trùng/xung đột với rules đang có. Không cài npm package như thể đây là DSH plugin. Ponytail không click trang, không điều khiển DOM, không thay Playwright hay browser-skill; trang board chỉ hiển thị metrics cục bộ. [Source board](https://github.com/DietrichGebert/ponytail/blob/09c434ab73ca43761c5d8b0c5d341926c2fba710/hooks/band/board.ts).

### Playwright — điều khiển trình duyệt và kiểm thử web

- Chromium, Firefox, WebKit trên Linux/macOS/Windows, headed/headless; Node library hỗ trợ JS/TS, có bindings Python, Java, .NET riêng. Manifest core tại commit đã pin yêu cầu **Node >=20**. Không suy ra mọi distro Linux đều được hỗ trợ chỉ từ bảng OS tổng quát. [README](https://github.com/microsoft/playwright/blob/20a2087ea43412b90c172c88faef80786ee18b8b/README.md), [manifest](https://github.com/microsoft/playwright/blob/20a2087ea43412b90c172c88faef80786ee18b8b/packages/playwright-core/package.json).
- Test runner: `npm i -D @playwright/test`, `npx playwright install`, `npx playwright test`; library: `npm i playwright`. Có browser context cô lập, locators, auto-wait, assertions, screenshots/video/trace và network interception. CLI agent (`@playwright/cli`) và MCP (`@playwright/mcp`) được README giới thiệu nhưng nằm ở **repository riêng**, không được đánh đồng với core hay mặc định coi đã audit trong nghiên cứu này. [README](https://github.com/microsoft/playwright/blob/20a2087ea43412b90c172c88faef80786ee18b8b/README.md).
- **Cho DSH:** phù hợp nhất cho E2E có thể chạy lặp lại trong CI và bằng chứng giao diện. DSH có thể gọi test qua shell; thêm MCP/CLI chỉ khi cần một giao diện browser chưa có. Không giả định một browser launch mới sẽ dùng phiên đăng nhập/profile của người dùng hoặc thay thế tích hợp browser hiện hữu.

## 3. Chi phí và ranh giới privacy/security

| Công cụ | Chi phí/rủi ro cần tính trước |
| --- | --- |
| Graphify | Local AST không cần LLM credits; semantic docs/media có thể gửi nội dung cho assistant/backend và tốn token. Cloud là lựa chọn riêng, không phải bằng chứng mọi đường chạy đều local. Graph/report chứa cấu trúc và thông tin dự án, cần bảo vệ như source. Có thêm chi phí dependency, CPU/RAM, rebuild/staleness. HTTP mặc định `127.0.0.1:8080`, API key tùy chọn; source cảnh báo bind `0.0.0.0` không key sẽ lộ graph. Ưu tiên stdio, tránh mở mạng. [README](https://github.com/Graphify-Labs/graphify/blob/c588b72d936927790a87ad009955078ed40562a3/README.md), [server](https://github.com/Graphify-Labs/graphify/blob/c588b72d936927790a87ad009955078ed40562a3/graphify/serve.py) |
| Ponytail | Rules chiếm context và vẫn dùng model của host; không có cơ sở bảo đảm giảm chi phí trên DSH. Hooks là code chạy với quyền host và có state/config ngoài repo; xem trước khi tin cậy. Band/board mặc định lưu tại `~/.config/ponytail/band/`, có thể import lịch sử Claude; board source không server/network nhưng tên task/project và metrics vẫn nhạy cảm khi chia sẻ. Không gọi đây là chứng nhận toàn repo không telemetry. [README](https://github.com/DietrichGebert/ponytail/blob/09c434ab73ca43761c5d8b0c5d341926c2fba710/README.md), [INSTALL](https://github.com/DietrichGebert/ponytail/blob/09c434ab73ca43761c5d8b0c5d341926c2fba710/INSTALL.md), [board](https://github.com/DietrichGebert/ponytail/blob/09c434ab73ca43761c5d8b0c5d341926c2fba710/hooks/band/board.ts) |
| Playwright | Cần tải browser binaries/dependencies, RAM/CPU, dung lượng traces/video và bảo trì tests. Actions có thể ghi dữ liệu thật trên website; context isolation không ngăn tác động server-side. Auth state chứa cookies/headers có thể mạo danh tài khoản: không commit dù repo private; ưu tiên account test, không dùng profile cá nhân. Trace/screenshots/network evidence có thể chứa bí mật và cần retention/redaction. [README](https://github.com/microsoft/playwright/blob/20a2087ea43412b90c172c88faef80786ee18b8b/README.md), [cảnh báo auth chính thức](https://playwright.dev/docs/auth) |

Thêm `tools/dsh-browser-smoke.py` để kiểm tra hiển thị desktop/mobile, ghi screenshot và JSON vào thư mục riêng. Smoke check là kiểm tra nhanh khả năng hiển thị, không phải kiểm thử toàn bộ chức năng.
- Chạy: `/home/dzerok/venvs/agentskills/bin/python tools/dsh-browser-smoke.py --output .dsh-browser-smoke/current`. Việc tải trang vẫn có thể kích hoạt các request khởi tạo bình thường của ứng dụng; đây không phải sandbox chặn mọi request ghi.
- Kết quả thực tế ngày 23/10/2026: desktop và mobile đều `auth-required`, HTTP **401**, lệnh exit **2** đúng để không báo xanh giả. Screenshot và `result.json` ở thư mục output nêu trên, không commit artifact. Phần giao diện sau đăng nhập **chưa verify**; script hiện chưa có cơ chế cấp phiên test và không tự lấy token người dùng. Không tắt authentication để chạy qua.
- **Ponytail:** không cài package/hook. Các nguyên tắc tối giản, tái sử dụng và kiểm chứng đã có trong `AGENTS.md` cùng `docs/vibe-native-playbook.md`; tránh thêm rules always-on trùng lặp. Áp dụng ở quyết định tái sử dụng Playwright hiện có thay vì dựng thêm adapter.
- **Graphify:** chưa cài; chưa có bằng chứng graph mang lại lợi ích lớn hơn chi phí vận hành đối với tác vụ hiện tại. Không bật Cloud, semantic pass hoặc chỉ mục always-on. Đây là quyết định không triển khai ở thời điểm khảo sát, không phải kết luận công cụ vô ích.

## 5. Khuyến nghị cuối

1. **Playwright: nên dùng cho E2E khi có nhu cầu cụ thể**, pin bản stable được chọn và browser tương ứng, dùng account test, xác minh đúng URL DSH đang chạy. Không cần thêm automation stack thứ hai chỉ vì có repo nổi tiếng.
2. **Graphify: thử nghiệm có kiểm soát, chưa bật always-on/Cloud.** Đo trên một repo: thời gian lập graph, độ mới, chất lượng truy vấn, số lượt đọc/token so với baseline. Bắt đầu AST local; semantic pass/MCP HTTP là quyết định quyền dữ liệu riêng.
3. **Ponytail: giá trị chủ yếu ở phương pháp, không phải năng lực browser.** Có thể trích nguyên tắc tối giản để review thủ công; chưa có lý do cài adapter không hỗ trợ DSH hoặc thay thế các guard/test hiện tại.
4. Các con số tiết kiệm token/cost trong README là **benchmark do upstream báo cáo**, không phải kết quả đo DSH; không dùng để hứa tiết kiệm hay bỏ kiểm thử. Chưa verify runtime compatibility, hiệu năng, chất lượng hoặc toàn bộ dependency security bằng thực thi; đây không phải security audit.
